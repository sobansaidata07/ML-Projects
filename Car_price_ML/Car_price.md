# 🚗 Car Price Prediction (Practice Project)

> Note: This project is for practice purposes using a small dataset (~2,500 rows). 
> The workflow demonstrates full end-to-end ML skills: data exploration, preprocessing,training multiple models, evaluating performance, and saving models. 
> Pre-trained models (`.pkl`) can be generated by running the provided script at end.


---

## 📝 Project Overview
This project demonstrates **Exploratory Data Analysis (EDA)** and builds **Machine Learning models** to predict car prices.  
The dataset contains details like **brand, year, engine size, fuel type, transmission, mileage, condition, model, and price**.

---

## 📂 Dataset
- **Rows:** ~2,500  
- **Columns:** 10  

**Columns:**
1. Car ID  
2. Brand  
3. Year  
4. Engine Size  
5. Fuel Type  
6. Transmission  
7. Mileage  
8. Condition  
9. Price  
10. Model  

**Observations:**
- No missing values or duplicates.
- Car ID is just an identifier and dropped for modeling.

---

## 🔍 Exploratory Data Analysis (EDA)

### Categorical Columns
- Toyota is the most common brand, followed by Audi and BMW.  
- Diesel is the most popular fuel type.  
- Manual cars slightly more common than automatic.  
- Car condition is evenly distributed: Used, Like New, New.  
- Most common models: Fiesta and Corolla (~4% each).

### Numerical Columns
- **Year:** Cars from 2000–2023, fairly evenly distributed.  
- **Engine Size:** 1.0–6.0 L, average ~3.5 L.  
- **Mileage:** Wide range from low to high.  
- **Price:** $5,000–$100,000, wide distribution.  

**Observations:**  
- No outliers in numerical columns.  
- None of the columns follow a normal distribution.

### Correlation & ANOVA
- Weak correlation between features and Price.  
- Only Fuel Type shows a borderline effect on Price.

---

## ⚙️ Preprocessing
- Categorical variables encoded using **OneHotEncoder**.  
- Numerical variables scaled using **StandardScaler** (`Year`, `Engine Size`, `Mileage`).  
- Train/Test split: **80/20**.

---

## 🤖 Machine Learning Models

### 1️⃣ Linear Regression
- Simple and interpretable.  
- **Performance:**  
  - RMSE: 27,794  
  - R²: -0.019  
- Predictions are close to mean prices.

### 2️⃣ Random Forest Regressor
- Handles non-linear data.  
- **Performance:**  
  - RMSE: 28,651  
  - R²: -0.084  
- Limited by weak features.

### 3️⃣ Gradient Boosting Regressor
- Advanced ensemble model.  
- **Performance:**  
  - RMSE: 28,448  
  - R²: -0.068  
- Features too weak; predictions near mean.

---

## 🔑 Feature Importance
**Top features (Gradient Boosting & Random Forest):**
- Brand, Fuel Type, Year, Mileage, Engine Size, Model, Condition, Transmission  

**Observation:**  
- Limited predictive features reduce model performance.
